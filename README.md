# Лабораторная работа №5

## Основное задание — позиционирование

Страница с цветными блоками по образцу из задания. Использована HTML-разметка из методички и простой CSS. Без JavaScript, библиотек и сборки.

- `static` — обычное положение в потоке.
- `relative` — смещение блока с сохранением его места в потоке.
- `absolute` — положение относительно ближайшего позиционированного родителя.
- `z-index` — порядок перекрытия позиционированных блоков.
- `fixed` — положение относительно окна браузера.

Откройте `index.html` в браузере. Стили находятся в `style.css`.

В корне репозитория и в папке `lb5` находится одинаковое основное задание. Новый сайт-визитка в это обновление не включён: он будет добавлен отдельно после правок владельца.
